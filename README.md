# Unlock The Psyche — GitHub Pages Website

This folder contains the complete static website for Unlock The Psyche.

## Files
- `index.html` — Home
- `about.html` — About the Psychologist
- `therapy.html` — Therapy
- `specializations.html` — Specializations / Concerns
- `how-therapy-works.html` — How Therapy Works
- `courses.html` — Certificate Course
- `course-details.html` — Course Details
- `resources.html` — Resources / Blog
- `faq.html` — FAQ
- `contact.html` — Contact
- `book.html` — Book an Appointment
- `privacy.html` — Privacy / Terms / Disclaimers
- `styles.css` — shared design system
- `script.js` — navigation, motion, demo form behavior
- `DESIGN_SYSTEM.md` — full art direction and IA notes

## Before launch
1. Replace every `[PLACEHOLDER]`.
2. Add approved professional photography to the visual blocks.
3. Replace the placeholder course information with verified curriculum, duration, fees, enrollment, assessment and certificate wording.
4. Add the practice's reviewed privacy, confidentiality, cancellation and emergency information.
5. Connect the booking/contact forms to the practice's chosen form or booking provider.
6. Test on mobile and desktop.
7. Upload the folder to GitHub and enable GitHub Pages.

The current forms are intentionally demo-only; they do not send or store submissions.
